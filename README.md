# Öredev 2026 – Knowledge Base

Obsidian-vault med anteckningar från Öredev 2026, fångade med Pocket. Innehåller sammanfattningar och mind maps från 11 sessioner.

> [!warning]
> Sammanfattningarna är AI-genererade och kan innehålla fel. Alla talk-noter har `status: unreviewed`.

## Kom igång

1. Klona repot: `git clone https://github.com/richardgrconsid/oredev-2026.git`
2. Öppna mappen som vault i [Obsidian](https://obsidian.md) (*Open folder as vault*).
3. Börja på `Home.md`.

## Struktur

- `Home.md` – startsida med länkar till alla ämnen och talks per dag
- `Talks/` – en note per session (börja här)
- `Topics/` – översiktsnoter som grupperar talks per tema
- `Templates/` – mall för nya talks
- `Attachments/` – mind maps och original-PDF:er

## Använd med Claude Code

Kör `claude` i repots rotmapp. `CLAUDE.md` gör att Claude svarar bara utifrån vaulten, anger källa (talk och rubrik) och skiljer på vad talaren sa och Claudes egna slutsatser.

## Bidra

Ändra inte befintliga talk-noter eller bilagor utan att prata med ägaren. Egna anteckningar skriver du under `My notes` i respektive talk, eller i en ny note i `Inbox/`.
